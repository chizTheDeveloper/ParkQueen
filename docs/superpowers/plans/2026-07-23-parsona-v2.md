# Dormant Premium Parsona v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare a fully validated, dormant Parsona v2 architecture and DEV review lab while preserving all public v1 behavior.

**Architecture:** A discriminated avatar union delegates unchanged v1 rendering to a dedicated component and approved v2 rendering to a local-manifest compositor. All v2 portrait assets begin pending, so production resolves v2 safely to deterministic v1 while the DEV lab uses a neutral review-only silhouette.

**Tech Stack:** React 18, TypeScript, Vite, Vitest, Firebase Firestore Rules emulator.

## Global Constraints

- Work only on `feature/parsona-avatar-creator`; do not merge, deploy, or modify `main`.
- `PARSONA_V2_PUBLIC_ENABLED = false` is the sole public enablement flag.
- Public Profile, onboarding, migration, preset, and creator flows remain v1-only.
- No fabricated portrait layers or reference-board assets enter the repository.
- Exact options: 2 base styles, 5 tones, 5 hairs, none plus 4 accessories, 5 tops, one background, 1,250 combinations.
- English and Spanish labels, accessibility, reduced motion, keyboard support, and 44 px targets are required.
